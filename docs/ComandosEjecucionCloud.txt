2. INSTALACIÓN
---------------------------------------------------------
* sudo apt upgrade
* sudo apt update 
* sudo apt install python3-pip awscli
* git clone https://github.com/DiegoPyLL/FlujoPRT
* cd FlujoPRT
* pip install --user -r deploy/requirements.cloud.txt



3. USO
       ---------------------------------------------------------
       1. EJECUCIÓN PERMANENTE (TMUX)
       ---------------------------------------------------------
       *   Crear sesión nueva:
              tmux new -s FlujoPRT_CCTV
              tmux new -s FlujoPRT_Dashboard
              tmux new -s FlujoPRT_CCTV_Validator
              tmux new -s FlujoPRT_CCTV_VehicleCounter

       *   Comando de ejecución FlujoPRT_CCTV:
              python3 src/imageRecopilator/Cloud/ImageRecompilerCloud.py
       
       *   Comando de ejecución FlujoPRT_CCTV_Dashboard:
              streamlit run scripts/realtime_dashboard.py --server.port 8501 --server.address 0.0.0.0
              http://54.166.187.247:8501
       
*   Comando de ejecución FlujoPRT_CCTV_VehicleCounter:
              sudo apt-get install -y libgl1-mesa-glx
              pip install ultralytics tqdm Pillow boto3

              # Configuracion por defecto (todo capturas/2026/)
              python3 scripts/VehicleRecognition/validate_vehiculos.py

              # Prefijo especifico (dia o mes)
              python3 scripts/VehicleRecognition/validate_vehiculos.py --prefijo capturas/2026/04/25/

              # Con umbral de confianza para boxes (0.55 filtra ruido bajo)
              python3 scripts/VehicleRecognition/validate_vehiculos.py --confianza-min 0.55

              # Las imagenes anotadas se suben a: s3://flujo-prt-imagenes/capturas_anotadas/
              # El log JSONL se sube a:           s3://flujo-prt-imagenes/metadata/validate_vehiculos/

       *   Volver a entrar a la sesión:
              tmux attach -t FlujoPRT_CCTV
              tmux attach -t FlujoPRT_Dashboard
              tmux attach -t FlujoPRT_CCTV_Validator
              tmux attach -t FlujoPRT_CCTV_VehicleCounter

       *   Ver sesiones activas:
              tmux ls

       *   Matar sesión (Reiniciar proceso):
              tmux kill-session -t FlujoPRT_CCTV
              tmux kill-session -t FlujoPRT_CCTV_Dashboard
              tmux kill-session -t FlujoPRT_CCTV_Validator
              tmux kill-session -t FlujoPRT_CCTV_VehicleCounter




       2. DESCARGAR / SINCRONIZAR DESDE AWS S3
       ---------------------------------------------------------
       *   Para configurar las credenciales del usuario s3-downloader
              aws configure 

       *   Sincronizar TODAS las capturas a carpeta local:
              aws s3 sync s3://flujoprt-bucket/capturas/ ./descargas_fotos/

       *   Bajar fotos de un día específico (Ejemplo: 22-Ene-2026):
              aws s3 sync s3://flujoprt-bucket/capturas/2026/01/22/ ./fotos_hoy/

       *   Bajar fotos de una planta específica:
              aws s3 sync s3://flujoprt-bucket/capturas/2026/01/22/Temuco/ ./fotos_temuco/

       







       3. LOGS Y DIAGNÓSTICO
       ---------------------------------------------------------
       *   Ver log en tiempo real (ajustar ruta según .env):
              tail -f /data/flujo_prt/logs/FlujoPRT_CCTV.log

       *   Buscar errores críticos en el historial:
              grep "CRITICAL" /data/flujo_prt/logs/FlujoPRT_CCTV.log | tail -n 20

       *   Verificar si FFmpeg está instalado (necesario para el domingo):
              ffmpeg -version

       *   Limpiar archivos temporales de Python (Cache):
              find . -type d -name "__pycache__" -exec rm -rf {} +
